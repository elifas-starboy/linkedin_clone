# LinkedIn Clone

A static front-end clone of the LinkedIn home feed and profile experience, built using HTML, CSS, and JavaScript.

This project recreates a clean social networking interface with a top navigation bar, profile sidebar, post composer, content cards, and a profile page layout inspired by LinkedIn.

## Features

- Responsive LinkedIn-style header and navigation
- Search bar and action icons matching the original layout
- Left sidebar with profile summary, recent activity, and groups
- Post composer and feed cards for social updates
- Profile page with cover image, intro, connections, and experience details
- Interactive UI elements such as profile dropdown and expandable sidebar activity
- Pure front-end implementation with no backend or database

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Local image assets

## Project Structure

```text
linkedin-clone/
├── index.html          # LinkedIn home page
├── profile.html        # User profile page
├── style.css           # Main styling for the app
├── queries.css         # Responsive media queries
├── script.js           # UI interactions
├── images/             # Icons and profile assets
└── README.md           # Project documentation
```

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/linkedin-clone.git
```

2. Open the project folder.
3. Launch `index.html` in your browser.

You can also use a local dev extension like Live Server in VS Code for a smoother preview experience.

## Pages

- `index.html` — Home feed page
- `profile.html` — Profile details page

## Notes

This is a front-end mockup intended for learning, practice, and UI design experimentation. It does not include authentication, real user data, networking backend functionality, or dynamic content.
